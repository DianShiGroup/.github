# 项目介绍

## MinerU.Chem

[MinerU.Chem](https://mineru.net/chem/) 是一个基于[MinerU](https://mineru.net/)的化学文献的智能解析引擎。能够把论文和专利中的分子结构与反应图式转化为 AI 可用的结构化数据。

## 点石数据库

[点石数据库](https://dianshi.opendatalab.org.cn/) 是一个化学物质、反应、文献一站式检索平台。包含约 2,400 万条、全自动构建的 AI-ready 有机反应。网页端与 MCP 服务同时为科研人员与 AI 智能体服务。
